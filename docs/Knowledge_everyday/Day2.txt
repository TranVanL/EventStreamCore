3. CPU affinity : Limited list CPU run on thread 
-> Help to reduce latency variance and increase determinism . 
-> Avoid CPU migration , keep cache hot , prevent cache pollution and stable execute time 
Special in multicore, keep the settel runtime from scheduler and workload on core . 
-> Diminish jitter and increase determinism 

cpu_set_t  cpuset;
CPU_ZERO(&cpuset);
const int result = pthread_setaffinity_np(thread , sizeof(cpu_set_t), &cpuset);
